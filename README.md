# Fluxo Bancário

Projeto de estudo para praticar os conceitos básicos de lógica de programação utilizando typescript, simulando operações de uma conta bancária.

## Funcionalidades

- Consultar saldo
- Depositar
- Sacar
- Ver extrato

## Conceitos praticados

- Variáveis e tipos de dados
- Condicionais (if/else)
- Laços de repetição
- Funções
- Vetores/listas
- Validação de dados (saldo insuficiente, valores inválidos)
